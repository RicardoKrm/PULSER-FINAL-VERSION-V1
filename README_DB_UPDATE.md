Para solucionar los errores PGRST205 (tablas no encontradas), debes ejecutar las sentencias SQL en tu base de datos Supabase.

1. Abre tu panel de Supabase y ve al **SQL Editor**.
2. Copia el contenido del archivo \`run_mina_tables.sql\` que se encuentra en la raíz del proyecto.
3. Ejecuta el código SQL para crear las tablas \`produccion_mina_mensual\`, \`produccion_cmc\` y \`produccion_cmc_totales\`.

Una vez ejecutado, los errores desaparecerán y podrás guardar los datos correctamente.
